# 🎨 LinkedIn Visual Pipeline

Специализированное приложение для создания вирусных LinkedIn-слайдов с помощью Google Gemini API.

## 📋 Возможности

Автоматическая генерация **4 типов визуальных слайдов** из любого текста:

1. **📋 Шпаргалка (Cheat Sheet)** - список из 5-7 шагов
2. **⚖️ Сравнение (VS)** - "Любитель vs Профи" или "До vs После"
3. **🔄 Процесс (Diagram)** - визуальная схема "Проблема → Решение"
4. **🏆 Вирусная Обложка (Cover)** - с Hook, Sub-hook и CTA

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Получение API ключа Gemini

1. Перейдите на [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Создайте новый API ключ
3. Скопируйте ключ

### 3. Запуск приложения

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу: **http://localhost:8501**

### 4. Использование

1. **Введите API ключ** в боковой панели (sidebar)
2. **Вставьте текст** LinkedIn поста или статьи в текстовое поле
3. Нажмите кнопку **"🚀 Generate Assets"**
4. Дождитесь генерации (обычно 30-60 секунд)
5. **Просмотрите** 4 сгенерированных слайда
6. **Скопируйте HTML код** из выпадающих блоков

## 📝 Пример входного текста

```
Как я увеличил конверсию на 300% за 2 недели

За последние годы я протестировал десятки методов оптимизации...
Главная ошибка новичков - они фокусируются на трафике, а не на конверсии.

Вот 5 шагов, которые работают:
1. A/B тестирование заголовков
2. Упрощение формы регистрации

4. Оптимизация скорости загрузки
5. Персонализация CTA

Результат: конверсия выросла с 2% до 8% за 14 дней.
```

## 🎨 Технические детали

### Архитектура (2-Step Pipeline)

**ФАЗА A: Анализ контента**
- Русский промпт анализирует текст
- Извлекает 4 концепции в формате JSON
- Создает заголовки, структуры и CTA

**ФАЗА B: Генерация HTML**
- Для каждой концепции отправляется запрос к Gemini
- Генерируется standalone HTML + Tailwind CSS
- Размер: 1080x1350px (формат 4:5 для LinkedIn)

### Стек технологий

- **Frontend**: Streamlit
- **LLM**: Google Gemini Pro
- **Styling**: Tailwind CSS (CDN)
- **Fonts**: Google Fonts (Inter, Anton, Roboto)

## 💡 Советы по использованию

1. **Качество входного текста**: Чем детальнее и структурированнее ваш текст, тем лучше результат
2. **Цифры и факты**: Gemini лучше работает с конкретными данными (проценты, доллары, сроки)
3. **Копирование HTML**: Каждый слайд - это самостоятельный HTML файл, просто скопируйте и сохраните как `.html`
4. **Редактирование**: Можно отредактировать сгенерированный HTML вручную в любом редакторе

## 🐛 Troubleshooting

### Ошибка: "Invalid API Key"
- Проверьте правильность ключа API
- Убедитесь что API включен в Google Cloud Console

### Ошибка: "Rate limit exceeded"
- Подождите несколько минут
- Проверьте лимиты вашего API ключа

### Слайды не отображаются
- Проверьте интернет-соединение (нужен доступ к Tailwind CDN)
- Обновите страницу в браузере
